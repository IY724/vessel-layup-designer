# 复合材料气瓶缠绕铺层设计系统 / Vessel Layup Designer

> 把"课程讲义 + 两张 Excel 手工迭代"的缠绕铺层设计流程，变成秒级、可视、可追溯的自动设计。

面向 Ⅲ/Ⅳ 型储氢高压复合材料气瓶的**缠绕铺层设计板块**：输入设计条件与材料工艺参数 → 点「自动生成铺层」在弹窗里给齐参数（缺项就地标红），算出的铺层方案**直接写入表单** → 在铺层表里改层数/角度，**实时看到**纵向/环向爆压、封头厚度轮廓与爆压曲线的变化 → 导出方案 JSON / Excel 计算书 / 打印 PDF。

计算依据为**网格理论（netting analysis）**：筒身等厚假设下的多角混合铺层校核，封头按缠绕规律（纤维体积沿平行圆守恒 + 三次样条）逐角度组校核。

## 快速开始

**只想用**：下载 Releases 里的 `index.html`（单文件），拷到任何机器上双击用浏览器打开即可——**零安装、零联网、零后端**。

**给别人用**：把 `dist/index.html` 发过去即可（或在 Releases 下载最新构建产物）。

**想改**：

```bash
npm install
npm run dev            # 本地开发 http://localhost:5173
npm test               # 基准测试（对照两张 Excel 的缓存值）
npm run build:single   # 产出 dist/index.html 单文件（分发给别人用）
```

## 它算什么

| 环节 | 内容 | 依据 |
|---|---|---|
| 工艺参数链 | tf = tex/(ρ·b)、tc = tf/Vf、总带宽 = n·b | 课件 3.3 |
| 强度 | 模式 A：σ_NOL/Vf·k 自算；模式 B：直接给定（螺旋/环向可分） | 课件 3.3 / 70MPa 案例 |
| 测地线 | r₀ = R·sinα ⇔ α = arcsin(r₀/R)，逐组扩孔 | 课件 2.4 / 3.4 |
| 筒身 | 多角混合 pα = Σn·2tfσcos²α/R、pθ = Σn·tfσsin²α/R + n₉₀·tfσ/R | 强度设计与计算.xls |
| 封头 | 覆盖公式 + 三次样条 → t_g(r)；局部参考曲线使用 cos²(Kπ/180)；经验初估使用筒身角 α₀、纤维强度与纯纤维厚度 | 封头课件与余弦项核查记录 |
| 初步判定 | 筒身双向 ≥ pb；封头经验初估 ks·Σ(2σfb·n·tf·cos²α₀/R) ≥ pb；局部曲线仅作参考 | 第六课第2页 |
| 自动生成 | 初估 → 角集"隔一取一" → 分配 → 补层修复 → 贪心删层 → 封头反馈置换 | 设计规划 §7 |

## 与课件原表的对齐

对外版本统一为 **V1.0**（内部构建号 1.0.0，界面、安装包、文档、发布资产同一标识）。V1.0 的网页、网站本地页面、桌面软件及 Excel 导出使用同一内核。余弦项统一为平方；筒身角 α₀ 的经验初估与局部角 K 的参考曲线分别计算。保留 144 个半径点、全部角度组、手选层数及 45° 组在 163 mm 处的分段。所有工作表显示原生网格线，空白区域无白色填充，数据表保留横纵边框。

公开导出保留全部参数、条件矩阵、逆矩阵、样条系数和逐点计算，不包含原版对比或修正提示。原表复现和公式核查记录仅用于内部维护。

详见 [本次同步记录](docs/版本同步_20261015.md) 和 [公式核查](docs/封头余弦项核查_20261015.md)。

## 目录结构

```
src/core/       纯计算核心（无 UI 依赖，可独立单测、可被 Abaqus 插件侧复用）
  types.ts        全部输入/方案/结果类型
  materials.ts    工艺参数链、强度模式 A/B
  geodesic.ts     测地线：角度↔极孔互算、极孔一致性校验
  netting.ts      网格理论：筒身单层/多层 pα、pθ、初估
  dome.ts         封头：覆盖公式+导数、V1/V2、样条求解、t_g(r)、p_g(r)、domeAt 精确求值
  checker.ts      汇总校核：判定范围、薄弱处定位、一致性检查、重量参考、调整建议
  designer.ts     自动铺层方案生成
  geometry.ts     几何板块：容积正反算、半椭球轮廓与主曲率、线型切点表、Ⅳ型瓶接头尺寸与约束链
  excelRef.ts     两套算法的公式对照表 + 参考表已知问题清单
  presets.ts      默认模板（基准算例数值；界面只暴露这一套）
src/ui/         输入面板 / 自动生成弹窗 / 铺层表 / 封头半剖轮廓与爆压曲线 / 几何面板 / 校核明细
                （手写 SVG，无图表库；Sym.tsx 负责把 r_sp 这类量名渲染成真下标）
src/state/      单一状态源：输入 + 方案 → 纯函数全量重算
tests/          基准测试（断言值 = Excel 缓存值 / 论文算例 / 插件基准）
tools/          对账脚本（需本地原始 .xls）
docs/           设计规划、GUI 设计图
```

## 范围

- ✅ 第一期：铺层设计板块（筒身设计 + 封头校核 + 可视化 + 自动生成 + 方案导出）
- ✅ 导出：Excel 复刻报告（默认 16 张表、单元格为**活公式**，可与原表并排对账）+ 方案 JSON 导出/导入 + 打印/PDF
- ✅ 几何板块（纯用户输参，不依赖 Abaqus 插件）：容积↔尺寸互算（朱宁式2.6/2.7，封头半椭球+筒身，
  未知量可选 l / R_in / λ）、内胆纵剖面轮廓、线型缠绕切点校验（郑强式2-4 + 表2-1）、
  Ⅳ型瓶接头尺寸设计与约束链（参数名/派生量/校验逐条对齐 `type4_builder_kernel.py`）
- ⏭ 下一里程碑：切点数/线型与扩孔的工艺闭环、螺纹与密封面几何（插件未建）、与 Abaqus 插件的程序级对接
- ⚠️ 输入参数与公式来自公开课件、基准算例与两篇硕士论文，**用于教学与预设计**；工程签发须按
  GB/T 35544 等标准与试验验证

### 界面文案约定（提 PR 时请遵守）

软件是给别人用的，所以**界面上不出现人名、课件页码、Excel 单元格号这类出处标注**，也不出现
"口径""判据奇异区"等只在讨论中成立的行话；量名一律渲染成真下标（`r_sp`、`σ_NOL` 写成 r<sub>sp</sub>、
σ<sub>NOL</sub>，不留下划线字符）。公式来源、对账依据、插件行号这些可追溯信息写在
`docs/DESIGN.md`、代码注释与本 README 里， Issue 里也请附**可复算的数值依据**。

模板只有一套，就叫「默认」（数值取自基准算例，便于开箱与参考表逐格对账）；封头按课件原表计算。

### 一个必须区分的量：两种"极孔半径"

Ⅳ型瓶插件里 **阀座通孔半径 `boreRadius r0`**（默认 16 mm）与缠绕的**测地线极孔 `r_cl = R_out·sinα₀`**
是两个不同的量（`type4_builder_kernel.py:13-15` 明确声明）。铺层设计里填的"缠绕极孔半径"是 **r_cl**。
软件在几何面板里把两者并列显示；封头判定范围的下界只用铺层自身的量（所有角度都铺到的最小平行圆），
不引入接头/阀座半径。
