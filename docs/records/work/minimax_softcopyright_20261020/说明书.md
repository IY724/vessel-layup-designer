# 复合材料气瓶缠绕铺层设计软件 V1.0 软件设计说明书

# 第一章 软件介绍

## 1.1 研发背景、软件定位与适用对象

复合材料储氢气瓶的承压层由内衬外的碳纤维缠绕层承担。筒身段采用网格理论进行等厚设计，封头段则要按各缠绕角度组的起铺圆、边界圆和衔接圆逐段推算厚度，并沿平行圆半径方向检查局部爆破压强是否达到设计值。这套计算的输入链条是"容积—线型—铺层—强度"：容积决定筒身段直径与长度，线型表里的转角档位决定内衬外形，铺层角度与层数决定承载能力，强度参数决定每一层能贡献多少爆破压强。链条中任何一环变动，后续结果都会随之改变，纸质表格在反复试算时极易出现前后不一致。

本软件把上述计算链条固化为一个可在单机离线运行的工作台：使用者按设计顺序输入容积与工况，软件实时给出线型候选、筒身层数初算、铺层方案、筒身双向校核与封头局部校核结果，并可把当前参数、公式、明细表格与图形一次性导出为 Excel 计算书和 PDF 计算书。软件面向的是初步结构设计与方案比选，而不是替代有限元分析：它给出的是可核对的解析结果与过程痕迹，让每一步取数都有出处。

软件适用于复合材料缠绕气瓶的初步结构设计环节，具体场景包括：车载储氢瓶的容积与外形定型、筒身缠绕角与层数的初始选择、封头局部薄弱区排查、同一工况下多个线型档位的方案比选，以及设计说明会与评审所需的计算书整理。适用对象是复合材料压力容器方向的工艺与结构设计人员、气瓶制造企业的工艺技术人员，以及承担相关课程或科研任务的师生。使用者应具备网格理论缠绕、测地线极孔换算与复合材料基本力学的基础知识。

## 1.2 核心功能概述

软件由六类功能构成。第一类是几何与线型设计，包括容积与尺寸互算、按容积驱动的线型切点候选生成、极孔与轴比合理性检查；第二类是材料与工艺换算，由线密度、纤维密度、单束带宽、纤维体积含量推出纤维单层厚、含树脂单层厚与总带宽；第三类是筒身铺层设计，支持按缠绕先后顺序排列的角度组、就地修改角度与层数、逐组激活与停用，并在表内直接给出纵向与环向贡献；第四类是封头校核，按各角度组生成厚度轮廓、沿平行圆半径给出爆破压强分布并标出薄弱区；第五类是结果判定与追溯，把判定结论、裕度、诊断提示、逐格计算明细、公式清单集中呈现；第六类是成果导出，输出带活公式的 Excel 计算书与带正文、公式、表格和图形的 PDF 计算书。

六类功能共享同一份设计输入：任一处的修改都会立即驱动其余部分重算并重绘，不存在需要手工同步的副本。软件不含网络请求，不上传设计数据，全部计算在用户本机完成。

## 1.3 单位制、符号与基础约定

几何量统一以毫米计，容积以升计并可在界面与计算书中换算，力与压强以兆帕计，线密度以克每米计，密度以克每立方厘米计。符号沿用气瓶设计的通行约定：R 为内衬外表面半径并作为缠绕与强度计算基准半径，r 为封头平行圆半径，r₀ 为缠绕极孔半径，α 为缠绕角，α₀ 为极孔处测地线角，t_f 为纤维单层厚，t_c 为含树脂复材单层厚，σ_NOL 为 NOL 环拉伸强度，σ_c 为复材层强度，p_b 为参与判定的设计爆压，k_s 为封头应力平衡系数，λ 为封头外表面轴比。计算按轴对称回转体假定进行，忽略内衬与树脂的承压贡献，纤维沿经线方向承受拉力，不计层间应力与损伤演化。

## 2.2 安装与启动方式

软件提供三种使用形态，三者共用同一套计算内核与界面。

一是桌面版。安装包形式双击安装后从桌面或开始菜单启动；免安装形式解压后直接运行可执行文件即可。桌面版把计算界面封装在独立运行环境中，不依赖系统是否安装浏览器，也不产生浏览器页面与地址栏，界面标题栏显示软件名称与版本号，状态栏显示当前版本号、计算内容与本机离线运行提示。

二是网页版单文件。软件的全部界面、脚本与样式被合并为单个网页文件，双击用浏览器打开即用，便于在没有安装权限的计算机上临时查看与演示。文件体积约五兆字节，可在无网络环境下打开。

三是开发者模式。以开发服务器方式启动时进入热更新模式，修改源码后浏览器即时刷新，用于功能验证与公式核对。

三种形态的界面操作完全一致：顶栏依次是自动生成铺层、恢复默认、导出 Excel 计算书、导出 PDF 计算书与校核明细五个入口，左栏是参数输入区，右栏自上而下是计算结果、筒身铺层方案、封头厚度与爆压分布、容积与尺寸互算、线型切点设计五个卡片，底栏是状态栏。

# 第三章 核心功能模块详述

## 3.1 工作台总体布局与参数输入面板

工作台采用左右分栏布局。顶栏横跨整个窗口，左侧为软件名称与版本号，右侧集中放置五个操作按钮；左栏是自上而下排列的参数输入区，宽度固定，内容超出时在栏内滚动；右栏是结果区，卡片纵向排列，卡片内的表格与图形随参数变化即时刷新；底栏为状态栏，显示版本号、当前计算内容、离线运行说明与最近一次操作的结果提示。

所有计算函数都是纯函数：输入一个设计参数集合，输出一个结果对象，界面只负责呈现。参数发生变化时，状态层重新执行一次完整计算，再把新结果分发给各张卡片，因此界面上的判定、表格、图形与明细始终来自同一次计算。

## 3.2 筒身铺层方案设计

铺层方案表是软件的核心交互区。表格每一行代表一组缠绕角度，列依次为激活开关、缠绕角、类型、层数、纵向贡献、环向贡献与厚度。首列默认显示组序号并参与计算，点击后显示叉号表示该组停用，行内数值变灰且不计入小计、合计与封头分组，再次点击可恢复。缠绕角可就地输入，类型可在螺旋与环向之间切换，层数通过增减按钮或直接输入修改。行与行之间可以拖动，行的先后顺序即实际缠绕顺序，序位变化会同时影响封头厚度轮廓的堆叠次序。右键点击某一行弹出菜单，可删除该层、在其上方插入或在其下方插入。表尾给出螺旋层与环向层的小计、合计与判定颜色，以及增加螺旋铺层、增加环向铺层与自动生成三个按钮。

## 3.4 容积互算与线型切点设计

几何设计卡片分两段。①容积与尺寸互算先选择求解对象：按尺寸算容积，或以目标容积反算筒身长、筒身段半径或封头轴比。反算结果可一键写回左侧几何参数，改动半径时同步更新封头深度以保持轴比不变。面板同时列出容积径向半轴、轴向半轴、封头容积、筒身容积与总容积，并给出长径比、轴比与极孔比三项合理性检查。

**表 5  几何合理性检查项与常用区间**
| 检查项 | 常用区间 | 超界提示方式 |
|---|---|---|
| 筒身长径比 | 2 至 5 | 提示当前长径比与含瓶口总长 |
| 封头外表面轴比 | 一般不大于 2.5 | 提示当前轴比并说明标准椭圆取值 |

# 第四章 总体执行流程与技术特点

## 4.1 系统逻辑架构与数据流

软件自上而下分为四层。表现层是界面组件，只接收参数事件并渲染结果，不做任何计算判断；状态层保存唯一的设计输入对象，提供按分组更新、按几何联动更新与恢复默认三种写入方式；计算层由纯函数构成，接收输入对象返回结果对象，内部再分为几何与线型、材料与强度、筒身校核、封头校核与方案生成五组；输出层把结果对象转成 Excel 工作簿与 PDF 文档。

数据流是单向的：界面事件写入状态层，状态层触发一次计算，计算结果对象同时分发给结果卡片、图形、明细窗口与导出器。计算层不引用界面代码，输出层不修改输入，因此同一组参数在任何入口下得到的数值完全一致，导出的计算书与屏幕上显示的数值同源。

## 4.2 端到端操作流程

典型操作流程分为七步。第一步，在几何参数区录入内衬半径、极孔半径、封头深度、筒身长度与目标容积，或在容积互算区用容积反算尺寸。第二步，在纤维与工艺区录入线密度、密度、带宽、并线束数与纤维体积含量，确认单层厚度与总带宽。第三步，在强度区选定强度输入方式并录入强度参数，在设计要求区确定设计爆压与应力平衡系数。第四步，在几何卡片②段查看线型切点候选，按需要点击采用确定筒身直径与长度。第五步，在筒身层数计算区完成初算，或直接点击自动生成铺层得到初始方案，再在铺层表中按需要调整角度、层数、顺序与激活状态。第六步，查看封头轮廓与爆压分布，确认薄弱区位置，通过放大图与悬停读数定位问题平行圆，必要时在铺层表中增减层数或用等厚置换把部分环向层换成高角度螺旋层。第七步，打开校核明细复核逐格数值，最后导出 Excel 计算书或 PDF 计算书归档。

## 4.3 核心技术特点

第一，单一数据源与即时重算。所有参数、结果、图形、明细与导出内容来自同一份输入对象和同一次计算，避免了表格之间的人工同步与版本错位。

第二，容积驱动的线型选择。把容积作为硬约束先导出芯模转角随直径变化的曲线，再与线型表允许转角求交，使外形确定与线型确定成为同一步操作的两个结果，与工程上"先定容积再定外形与线型"的实际顺序一致。

第三，封头厚度的分段处理与体积守恒。厚度在极孔两倍总带宽内用三次样条插值，在其外侧改用覆盖公式，两段在衔接圆处保持数值与斜率连续，样条系数由边界条件与纤维体积守恒条件联立确定，避免出现厚度突变或总量不符。

第四，铺层表以实际缠绕顺序为组织方式。行序即缠绕次序，角度、层数、类型均可就地编辑，停用机制让方案比选不必删改原始数据，拖动与右键插入使铺层表的调整动作与工艺文件的表述习惯一致。

第五，过程可追溯。任一结论都能下钻到逐格数值、所用公式与来源口径，诊断条目把不满足的原因与缺口数值直接写出，计算书把同样的内容固化为可归档文件。

# 第六章 系统校验与异常处理

## 6.1 前置合法性防御

软件在计算前对输入做整体校验。校验对象包括缠绕基准半径、封头深度、筒身长度、目标容积、纤维单层厚、复材单层厚、总带宽、螺旋与环向发挥强度、复材层强度、设计爆压与应力平衡系数，上述量必须为有限正数；纤维体积含量必须大于 0 且小于 1；内衬厚度不得为负，且必须小于外半径与封头深度；缠绕极孔半径必须大于 0 且小于基准半径；启用状态的铺层层数必须为正整数；螺旋角必须严格位于 0 度与 90 度之间，环向角允许在 0 度至 90 度之间取值。任何一项不满足时，计算结果仍会给出，但判定区标记为不满足，并在诊断条目中指名缺失项。

出现错误后的处理顺序是：先在左侧参数面板改正被点名的输入项，判定区随即刷新；再在校核明细窗口确认相关分组数值已变化；若强度类诊断仍在，则回到铺层表调整角度、层数或启用状态；若封头薄弱区诊断仍在，则在爆压分布放大图中用悬停读数确定薄弱半径，核对对应角度组在该半径的层厚与贡献，再决定增加该组层数还是做等厚置换。调整完成后重新导出计算书，汇总页的判定与诊断条目会同步更新，形成可归档的完整记录。
