# 复合材料气瓶缠绕铺层设计软件 — 设计规划

> 2026-10-07 · 第一期范围：**铺层设计板块**（筒身设计 + 封头校核 + 可视化 + 方案导出）
> 几何板块（容积驱动的外形生成）预留为第二期，本期只接收 Excel 表范围内的几何参数。

---

## 1. 目标

用户输入气瓶设计条件与材料/工艺参数 → 软件**自动生成满足爆破压强要求的铺层方案**（螺旋角组合 + 各组层数 + 环向层数）→ 用户可手动微调层数/角度并**实时看到**爆破压强、厚度曲线的变化 → 一键导出复刻两张 Excel 的校核报告。

核心价值：把"课程讲义 + 两张 Excel 手工迭代"的流程变成秒级、可视、可追溯的自动设计。

**发现并需处理的 Excel 笔误**：封头表各 sheet L 列（局部爆破压强）公式为
`2·J·σ/R·COS(K·cos(K))`（等价于 cos(K·cos K)，括号配平、Excel 不报错），应为 **cos²K**。
小角度时两者几乎相等，极孔附近（K→90°）差异巨大（0.995 对 0.004），导致极孔边缘爆压虚高。
软件统一实现**修正版** cos²K；作者本意为 cos²α₀（第六课讲义第 2 页印刷体）。

## 3. 全流程设计（领域流程）

```
设计条件输入
 ├─ 几何：筒身半径R、极孔半径r₀(缠绕值)、(信息记录：封头短半轴、筒身段长度、容积)
 ├─ 材料/工艺：线密度、纤维密度、带宽、纱数、Vf、强度(两种模式,见§5.2)
 └─ 设计要求：设计爆破压强pb(或工作压力×安全系数)、应力平衡系数ks
        │
        ▼
① 测地线角度↔极孔互算   r0g = R·sinαg  ⇔  αg = arcsin(r0g/R)
   （候选螺旋角集 = 课件经验值，用户可编辑；最低角度组对应瓶口极孔）
        │
        ▼
② 筒身铺层设计（网格理论,等厚假设）
   初估：h螺=R·pb/(2σf·cos²αref)，h环=(2−tan²αref)·R·pb/(2σf) → 层数=h/tf
   方案：Σni·pαi ≥ pb 且 Σni·pθi+n90·pθ90 ≥ pb  （自动生成或手动调整）
        │
        ▼
③ 筒身校核：pα、pθ、裕度、总厚度（复刻强度设计表）
        │
        ▼
④ 封头校核（逐角度组,复刻封头表）
   每组：覆盖公式(2带宽外) + 三次样条(2带宽内,体积守恒) → t_g(r)
   局部角αg(r)=arcsin(r0g/r)，组爆压 p_g(r)=2·t_g·σc/R·cos²αg(r)【修正笔误】
   汇总：t总(r)=Σt_g(r)；p总(r)=ks·Σp_g(r)
        │
        ▼
⑤ 判定与诊断：min p总(r) ≥ pb ? 一致性检查 t总(R)≈筒身螺旋层厚 ?
   薄弱区定位（各组极孔之间的空档）→ 调整建议（如环向层换高角螺旋层）
        │
        ▼
⑥ 输出：方案表 + 复刻两张 Excel 的 xlsx 报告 + 方案 JSON
```

要点（已在资料研读中确认的设计逻辑）：
- **筒身与封头必须分开算**：封头上 R、α 随位置变化；环向层上不了封头；封头厚度是缠绕规律的"结果"（纤维体积沿平行圆守恒），不是设计变量。
- **扩孔**：测地线把 α↔r₀ 绑死（r₀=R·sinα），每个角度组有自己的极孔半径 r0g，逐组增大——这正是扩孔工艺；候选角度集按课件经验选 8~10 组。
- **角度范围是经验设计**（课件原则 + 用户确认）：软件把候选角度集做成可编辑默认项（如 10/12/15/17/20/25/30/37/40/45°，上限默认 45°），不做连续角度域的盲目优化。

## 4. 软件总体设计

### 4.1 技术选型

**推荐：纯前端单页应用**（Vite + React + TypeScript），构建产物为纯静态文件，双击 `index.html` 或本地起静态服务即可离线使用。

理由：
- 全部计算是解析公式（毫秒级），滑块拖动层数/角度需要**即时重算+重绘**，纯前端体验最好；
- 零安装、零后端、易分发（单文件夹拷走就能用）；
- Excel 导出用 SheetJS（xlsx.js）纯前端完成；图表用 ECharts（中文文档、交互好）。

备选：Streamlit（若希望留在 Python 生态、方便日后与 Abaqus 脚本同仓）。缺点是每次交互整页重跑、打包分发麻烦。**计算公式将以"公式规范 + 单元测试基准（对照 Excel 数值）"固化**，将来无论 Python 版几何模块还是 Abaqus 插件侧复算，都按同一基准对齐。

### 4.2 模块划分

**数据流**：单一 state（输入 + 当前方案）→ 任何改动 → core 纯函数重算（<10ms）→ 视图全量刷新。无隐藏状态，"表格里改一层，三处（判定、筒身图、封头曲线）同时变"。

## 5. 参数输入设计（用户填什么）

> **输入总原则：经验取值一律"内置默认 + 允许自填"。**
> 所有来自课件/国标/基准算例的经验值（损失系数、ks、安全系数、Vf、带宽、候选角度集等）都以内置默认值预填在界面上，**每一项都可由用户修改**。软件不做任何用户改不了的隐藏假设。
>
> **模板只有一套，命名「默认」**（`presets.ts: defaultInput()`，数值取自 140 L / 35 MPa 基准算例，
> 便于开箱与参考表逐格对账）；不再提供"课程案例 / 强度预设"等多套模板下拉。
>
> **界面文案约定**：界面上不出现人名（郑强/朱宁）、课件页码、Excel 单元格号等出处标注，也不用
> "口径""判据奇异区"这类行话；量名一律渲染成真下标（`Sym.tsx`），不出现下划线字符。
> 出处与对账依据保留在本文件、代码注释与 Issue 模板里。

### 5.1 几何参数（第一期，即 Excel 范围）

| 参数 | 说明 |
|---|---|
| 筒身段半径 R (mm) | 或直接填直径，二选一 |
| **极孔半径 r₀（缠绕值）** | **口径二选一，界面明确标注**：① 直接填缠绕极孔半径（公式直接用）；② 填成品瓶口内半径 + 极孔处内衬厚度，软件自动相加得缠绕极孔。与最低角度组做一致性校验：r₀ ≈ R·sinα_min，不符时提示 |
| 封头短半轴 h (mm)（椭圆封头） | 第一期仅记录并显示（封头厚度公式不依赖它），第二期几何/重量用 |
| 筒身段长度、设计容积 | 第一期仅记录（网格理论等厚与长度无关），用于重量估算展示，第二期驱动几何 |

### 5.2 材料 / 工艺参数

| 参数 | 默认（课程案例 T700） |
|---|---|
| 线密度 tex (g/m) | 1.65 |
| 纤维密度 (g/cm³) | 1.8 |
| 缠绕带宽 b (mm) | 5 |
| 每束纱数 n → 总带宽 b_tot = n×b (mm) | 4 → 20 |
| 纤维体积含量 Vf | 0.6 |

派生（自动算，展示过程）：
- 纤维单层厚 tf = tex / (ρ·b) = 0.1833 mm（单位自洽：g/m 与 g/cm³ 差 10⁻³ 抵消）
- 复材单层厚 tc = tf / Vf = 0.3056 mm

**强度参数——两种模式（用户明确要求区分）**：
- **模式 A（软件自算）**：输入 NOL 环拉伸强度 σ_NOL + 强度损失系数 k（0.8~0.9）→
  σ发挥 = σ_NOL / Vf × k（课程案例 2390/0.6×0.85 = 3385 MPa）；
  复材层强度 σc = σ发挥 × Vf = 2031 MPa。
- **模式 B（用户直接给定）**：直接填 σ发挥（可螺旋/环向分别给，如 70MPa 课程案例 3859/4342 MPa）与 σc。

### 5.3 设计要求

| 参数 | 说明 |
|---|---|
| 设计爆破压强 pb | 两种给法：直接填（课程 90 MPa）；或填工作压力 + 安全系数（GB/T 35544 口径，35MPa 瓶用 ~2.57，70MPa 瓶用 2.8），软件换算 |
| 应力平衡系数 ks | 默认 0.75（Excel 取值；讲义 ~0.7），可调 |

### 5.4 自动生成弹窗里给的参数

顶栏「自动生成铺层」打开一个弹窗，**生成所需的驱动参数全在弹窗里给**（值从当前表单带入、可就地改）：
目标爆压、筒身半径、缠绕极孔半径、纤维与工艺（tex/密度/带宽/纱数/Vf）、强度（两种给法）、
候选角集与取法、是否强制偶数层、初估参考角。

| 项 | 默认 |
|---|---|
| 候选螺旋角集 | 常用集 10/12/15/17/20/25/30/37/40/45°（**可自由增删**） |
| 角度取法 | "隔一个取一个"（从等差序列隔一个抽取，如 10/20/25/30 → 取 10/25；用户确认的经验规则），可选"候选角全用" |
| 螺旋层必须偶数（±成对） | 强制（缠绕物理要求） |
| 优化目标 | 最小总厚度（默认）/ 指定裕度（如 pθ/pb ≥ 1.05） |

**交互约定（用户明确要求）**：参数缺失或不合法时，对应输入框标红并在弹窗里列出还差哪几项，
生成按钮禁用；参数齐了就直接把算出的铺层方案**写入表单并关闭弹窗**，不额外弹提示、不显示过程流水。
铺层表始终可改，改一格即全量重算。

> **不设上限**：层数、角度组数均无上限约束（用户明确要求）；约束不可行时算法**明确报错**并给出原因（哪个方向差多少），不做静默截断。

## 6. 输出与可视化设计

### 6.1 总览卡片
纵向爆压 pα、环向爆压 pθ、取 min 与 pb 设计对比、裕度%、筒身总厚（螺旋+环向）、封头最小爆压及其位置 r*、绿/红判定灯。

### 6.2 筒身面板
- **铺层表**（核心交互件）：行 = 角度组（螺旋 10°×4 … 45°×2 / 环向 90°×23），列 = 层数（可编辑/步进按钮）、单层 pαi、pθi、组贡献、组厚度。**行数不限、表格可滚动**（用户明确要求：铺层组可能很多）；改动即时刷新一切。
- **分组小计行**：**螺旋层总厚（层数+mm）与环向层总厚（层数+mm）单独展示**（用户明确要求，Excel 同口径），再给合计行。

### 6.3 封头面板（椭球截面一层层轮廓 + 爆压曲线，均⤢可弹出）

  - **关于中段"鼓包"**：它是封头 Excel 模型本身的输出，不是绘制误差——覆盖公式在约 1 带宽处存在虚假厚度尖峰，课件用三次样条＋纤维体积守恒把这部分体积摊开成鼓包，加之各角度组覆盖交界的起伏。轮廓线如实绘制并标注说明（用户已知情）。

- ~~t总(r) 曲线图~~：用户确认不要曲线形式（"涂起来了"），由椭球截面几何轮廓取代，精确数值在校核明细。
- ~~各角度组贡献分解图~~：用户确认不需要。
- **布局**（本轮定稿）：铺层表拉通整行（行数不限、可滚动）；封头校核面板左=几何轮廓、右=爆压曲线；图表均可"⤢ 弹出"独立大图窗口。
- 拖动层数/角度 → 轮廓线与爆压曲线即时重绘（毫秒级）。

- 在线完整数值表：逐格对应两张 Excel（参数区、缠绕角参数、螺旋/环向强度计算、封头各角度组的 r0/rb/r2b/mR/Vconst/m1..m4/厚度/层数/局部角/爆压、总厚度、总爆破压强）。

## 7. 自动方案生成算法（designer.ts）

**问题**：min Σ(层数·tc)  s.t.  Σni·A_i ≥ pb·mα，Σni·B_i + n90·B90 ≥ pb·mθ，
其中 A_i = 2·tf·σf·cos²αi/R（纵向），B_i = tf·σf·sin²αi/R（环向承载侧贡献），B90 = tf·σf/R；
约束：角度∈候选集、螺旋层偶数、层数上限。

**步骤**（毫秒级，无需重型求解器）：
1. **初估**：参考角 αref=20° 单角公式得螺旋/环向厚度与层数下限（复刻 Excel 左列逻辑）；
2. **角度组抽取**：候选序列上按课件经验**"隔一取一"**规则抽样生成初始角度组（如 10/20/25/30 → 取 10/25），或用户手动指定角度组；
3. **LP 松弛**：角度集上连续解（二维对偶/单纯形，变量数不限）；
4. **取整**：每组向上取整、螺旋层调成偶数（**层数无上限**，不可行时明确报错并给出缺口方向与数值）；
5. **贪心删层**：裕度超过目标时，按"性价比"（单位厚度贡献）从最低组逐层删，直到刚好达标或到下限；
6. **封头反馈**：用生成的方案跑封头校核，若薄弱区不足 → 建议并自动尝试"环向层数 → 高角螺旋层"的等厚度置换，重算至满足或报告无解原因；
7. 输出方案 + 生成依据（每步数值可追溯，报告中保留）。

铺层表始终可改：自动方案只是起点，表格即改即算（不再有"自动/手动"模式开关）。

## 8. 核心公式规范（实现依据，已对照 Excel 验证）

### 8.1 筒身（强度设计表）
```
tf = tex/(ρ·b)                    tc = tf/Vf
h螺(α) = R·pb/(2σf·cos²α)         h环(α) = (2−tan²α)·R·pb/(2σf)
n螺 = ceil(h螺/tf)                n环 = ceil(h环/tf)
pαi(单层) = 2·tf·σf·cos²αi/R      pθi(单层) = tf·σf·sin²αi/R
pθ90(单层) = tf·σf/R
pα = Σ ni·pαi ≥ pb                pθ = Σ ni·pθi + n90·pθ90 ≥ pb
厚 = (Σ螺旋层数 + n90)·tc（分组计）
```

### 8.2 封头（封头表，逐角度组 g）
```
r0g = R·sinαg        rb = r0+btot        r2b = r0+2·btot
mR = 2πR·cosαg/btot  nR = 1              tp = tc          tR = 2·nR·tp

覆盖公式 (r ≥ r2b):
  tcov(r)  = (mR·nR·tp/π)·[arccos(r0/r) − arccos(rb/r)]
  tcov'(r) = (mR·nR·tp/π)·[ r0/(r·√(r²−r0²)) − rb/(r·√(r²−rb²)) ]

Vconst = V1 + V2（闭式已数值验证，V1=18367.7913, V2=13896.9294 @10°）:
  V1 = mR·nR·tp·[ rb²·arccos(r0/rb) − r0·√(rb²−r0²) ]        （rb→r2b 区间精确积分）
  V2 = (r2b²−rb²)·mR·nR·tp·[arccos(r0/r2b) − arccos(rb/r2b)]  （= π·(r2b²−rb²)·tcov(r2b)）

样条 (r0 ≤ r ≤ r2b): t(r) = m1+m2·r+m3·r²+m4·r³，4 条件：
  t(r0)=tp·nR;  t(r2b)=tcov(r2b);  t'(r2b)=tcov'(r2b);
  ∫r0..r2b 2πr·t dr = Vconst
  → 4×4 线性方程组（系数行 [π(r2b²−r0²), (2/3)π(r2b³−r0³), (π/2)(r2b⁴−r0⁴), (2/5)π(r2b⁵−r0⁵)]）

组厚度  t_g(r) = I23·t(r)，I23 = 该组层数的一半（缠绕循环数：10/17/25°×4层→2；37/40/45°×2层→1）
        ★每组各自取值，不能一律×2；r < r0g 时 t_g = 0
        校验：t总(R) = 5.74 ≈ 筒身螺旋层 5.50（封头→筒身螺旋层连续，无缝衔接✓）
局部角  αg(r) = arcsin(r0g/r)
组爆压  p_g(r) = 2·t_g(r)·σc/R·cos²(αg(r))   ★修正 L 列笔误；原样模式保留 COS(K·cos K)
汇总    t总(r) = Σ_g t_g(r)                  p总(r) = ks·Σ_g p_g(r)
真实曲线特征（复算确认）：t总 峰值 10.55@r≈83、谷 7.99@r≈104、t总(R)=5.74；
p总×ks 峰值 ≈104@r≈93，近赤道 r≈150.5~R 低于 90（min 79.4@R，×ks 口径偏保守，
r→R 由筒身段公式不乘 ks 接管：pα=102.1≥90✓）；极孔附近低值=金属接嘴补强区（正常）。
```

## 12. 实现期对账修正（2026-10-08，代码落地时逐点复算得到）

规划定稿后，实现阶段用 `tools/verify_excel_baseline.py` 对封头表 144 个格点逐点对账，三处结论需要修正/补充：

1. **§2 关于笔误影响范围的描述偏窄**。原文写"小角度时两者几乎相等，极孔附近差异巨大"。
   实测：每个角度组在**自己**的极孔边缘（r → r0g）局部角 K → 90°，因此笔误使**整条中段曲线**系统性虚高，
   而不只是最外侧极孔附近。课程案例最大偏差 **+86.0 MPa @ r=81**（`cos(u·cos u)` 与 `cos²u` 之差）。
   原样口径与 Excel B 列逐点吻合（max 0.0028 MPa），修正口径即 §8.2 的实现。

2. **§9 的"Excel 原样复算"口径需要精确定义**，否则复现不出原表：
   - 厚度：`r ≤ r2b → max(0, 样条)`，`r > r2b → 覆盖公式`。即作者在样条转负处手工留空，
     但保留了 r0 下方 1~2 个格点的正值外插（最大 0.45 mm）。按此规则与「总厚度」表逐点一致 ≤1e-4 mm。
   - 爆压：`r < r0` 处 K 列 `#NUM!` → L 列手工置 0，两种口径都要先做这个门限。
   - 软件默认（corrected）口径统一为 `r < r0 → 该组厚度与爆压均为 0`，与 Excel 仅在上述孤立格点差 ≤0.45 mm。

3. **§6.3 的"薄弱区 min 79.4 @ r=R"不再是默认结论**。修正口径下曲线在每个 r0g 正上方都有承载空档谷，
   课程案例判定窗口内最小值出现在 r≈50.4（最低角组极孔之上）为 73.5 MPa，而 r=R 处为 79.4 MPa。
   因此新增显式参数 **r_boss（判定窗口下界，可改）**，并把诊断分成两类：极孔侧承载空档
   （环向⇄高角螺旋置换**无效**）与近赤道薄弱（置换**有效**）。§7 第 6 步的封头反馈只在后一类触发。

4. **r_boss 的取值口径已定（2026-10-08 用户拍板：只按铺层自身的量，不引入接头/阀座半径）**。
   三个候选里：
   - 取 `min(r0g)`（复合层最小平行圆 = 测地线极孔 r_cl）会让判据**退化**——该处只有一组覆盖且
     局部角→90°，cos²α 判据给出 p→0，最小值恒为 0，永远判不过；
   - 取接头的 `r_sp` 属于把接头概念拉进铺层判定，用户明确不要；
   - **采用 `max(r0g)` = 全铺层覆盖起点**（课程案例 45° 组 → 122.68 mm）：不奇异、只用铺层量，
     判定窗口 [max(r0g), R] 内薄弱点回到近赤道，min ≈ 79.4 MPa @ r=R，与 §6.3 的原始叙述重新一致。
   极孔侧区段 [min(r0g), max(r0g)) 仍完整画出并报出最小值（标记为"判据奇异区，仅参考"），
   不隐藏。界面 r_boss 可手动改，改小后诊断会点名提示落进了奇异区。

   实现注记：建议生成 `buildAdvice` 会试算置换方案，若走完整 `runCheck` 会与之互相递归
   （新窗口口径下退出条件不再触发，实测死循环）。已抽出 `evaluatePlan` 纯计算切断。

5. **线型切点口径（2026-10-16 补齐出处）**：长径比经验区间 2~5 出自朱宁 2023 论文 §2.3.3（正文 p18，
   原文"根据经验，IV 型储氢气瓶内衬长径比通常为 2~5"；其做法是先由 2~5 圈定筒身外径 D 的范围
   再挑线型档位）。郑强 2008 论文对应段落用的是 2~4（图 2-2，其算例 D=128.5~156.2 mm）。软件沿用
   2~5（与 ① 校验行、候选表标黄一致）；允许转角窗口 450°~660°、切点数 ≤4 是软件收窄的取法
   （线型表 360°(m+K/n) 本身不含窗口限制）。术语按两篇论文统一为"芯模转角 θn"（往返一次），
   界面与导出不再写"双程转角"。候选表超区间只标黄不剔除：整车安装空间等外部约束留给用户权衡。
   线型表（表 2-1）以原表插图（郑强 2008 p14）放入界面「?」弹窗与计算书「线型切点设计」页，
   保证与原表逐格一致（含切点数纵向合并、各格斜线、原表印字：n=1 行印 1880°、n=4 第二行 K 栏印 2，
   均照原表保留）；软件不再重排该表。

6. **尺寸流程与命名口径（2026-10-16 打通）**：论文的设计顺序是"先定容积与工况 → 线型切点定筒身
   直径 D 与筒身长 l → 再铺层缠绕计算"。软件据此把几何面板接成单一数据源：① 与左侧几何参数共
   用同一组字段（改哪边都是改同一个数，下游实时重算）；② 以显式「目标容积 V（设计指标）」为约束
   出候选，点「采用」把 D、l 写回几何参数并保持封头轴比 λ 不变（即封头深度 h = R/λ 随 R 联动）；
   ① 的反算结果同样可「采用」，R、l 带来源徽标（手填/②采用/由容积反算）。任何字段允许手填
   （哪怕不合理），只由既有校验行提示、不拦截。命名统一：软件里只有一条半径——「筒身段半径 R」
   （Excel 口径的缠绕参考半径，容积与线型公式均按它计），对应直径一律写「筒身直径 D = 2R」；
   废弃"外径 D""筒身内半径 R_in = D/2−t"两种互相打架的写法（geometry.ts 的 VolumeParams.R_in
   字段沿用原名，仅内部使用）。封头厚度轮廓图的筒身段由各缠绕层轮廓线水平延伸而成（不画壁厚带），
   只标"筒身段"三字。
