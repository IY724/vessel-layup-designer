# 复合材料气瓶缠绕铺层设计软件 V1.0 软件设计说明书

## 1 软件介绍

### 1.1 软件概述与研发背景

高压储氢气瓶（如 35MPa 与 70MPa Ⅲ型金属内胆与 Ⅳ型塑料内胆全缠绕碳纤维复合材料气瓶）是氢能汽车与高端储运的核心装备。气瓶由内胆与外部高强度碳纤维缠绕层复合构成，在内压作用下展现出高度复杂的各向异性空间力学响应。结构设计不仅需要满足气瓶筒身段的纵向与环向抗内压承载要求，更需精确解决变曲率椭球封头处纤维由赤道向极孔聚集重叠导致的厚度空间非线性演化、近极孔过渡区材料体积沉积守恒、测地线稳定缠绕角度演变以及多轴数控缠绕机速比闭合等一系列工程技术难题。

在传统的工程设计流程中，设计工程师通常借助静态离散的试算表格进行层数估计，缺乏直观的空间几何轮廓展现，且几何外形设计与数控机床缠绕线型切点计算相互割裂，严重制约了高压复合材料压力容器的研发迭代效率。

「复合材料气瓶缠绕铺层设计软件」（英文简称 VesselLayup）V1.0 是一款面向储氢气瓶结构设计研发、工艺拟定与安全校核的专业计算机辅助工程（CAE）设计分析软件。本软件采用先进的纯前端单页架构，将材料微观力学换算、容积驱动的外形逆向求解、数控线型切点求交、筒身网格理论双向承载校核、封头三次样条边界值配准矩阵模型与局部爆压空间判据深度集成于一体，为复合材料气瓶设计提供了高精度、高可靠、全离线、极速响应的数字化工作台。

### 1.2 软件建设目标与核心特点

本软件立足于解决高压复合材料气瓶工程设计中的关键痛点，确立了以下核心建设目标：

1. **纯前端免安装单文件分发**：运行时零依赖外部后端服务器与数据库，整套系统打包为单一独立的 HTML 网页文件，双击即可在主流浏览器中高速离线运行，从物理层面切实保障核心工业设计数据的私密安全。
2. **多物理力学模型闭环求解**：将几何尺寸反求、测地线极孔映射、网格理论双向等承载、封头三次样条体积守恒与局部爆压判定融为一体，彻底消除多软件反复导入导出的参数割裂。
3. **毫秒级全链路实时响应**：全模型单次重新求解耗时小于 8 毫秒，任何输入参数微调或铺层表格行拖拽排序，均可瞬间并发驱动筒身承载指示器、封头剖面厚度堆叠线图与母线爆压安全曲线等多个视角的无缝重绘刷新。
4. **原生 MathML 数学公式动态排版**：内置轻量级公式解析器，在浏览器底层直接调用原生标签高质量渲染复杂力学分式、上下标与动态拉伸括号，实现计算原理所见即所得。
5. **高保真活公式 Excel 计算书导出**：底层直接构建符合 OpenXML 规范的工程表格，导出的每个单元格均保留原生 Excel 动态活公式与自动重算指令，支持第三方审图机构进行动态追溯复核。

### 1.3 适用场景与用户群体

本软件广泛适用于以下典型工程与科研领域：
1. **车载高压储氢气瓶研发**：用于 35MPa/70MPa 车载储氢瓶、无人机供氢气瓶缠绕铺层方案设计、轻量化减重优化与爆破承载校核；
2. **特种复合材料压力容器研制**：用于固体推进剂火箭发动机壳体、高压充氦气瓶及复合材料管路的力学强度验算与数控工艺参数定型；
3. **高等院校与科研院所科研教学**：用于网格理论（Netting Theory）、复合材料各向异性力学、测地线缠绕轨迹及纤维沉积体积守恒算法的科研论证与仿真教学；
4. **特检机构与工程校审审计**：用于对气瓶设计图纸及工艺计算书进行逐项对账、极限强度校核与合规性评估。

主要用户群体包括复合材料结构设计工程师、缠绕制造工艺工程师、压力容器校审专家、科研人员以及力学与材料专业高校师生。

## 2 运行环境与安装使用

### 2.1 软硬件环境要求

本软件基于高效率前端运算模型开发，具有极高的硬件适应性与低资源消耗特性，支持跨平台运行：
- **硬件环境要求**：
  - 中央处理器（CPU）：双核 1.6 GHz 及以上 x86/x64 或 ARM 架构处理器（推荐四核 2.4 GHz 及以上）；
  - 系统内存（RAM）：最低 2.0 GB 可用物理内存（推荐 4.0 GB 及以上）；
  - 硬盘存储空间：预留 200 MB 磁盘空间；
  - 显示设备分辨率：最低 1366×768 像素（推荐 1920×1080 及以上全高清分辨率）。
- **软件与操作系统环境**：
  - 操作系统：Windows 7 / 10 / 11（32位/64位）、macOS 10.15 及更高版本、主流 Linux 发行版（Ubuntu、CentOS、Debian 等），以及国产安全操作系统（统信 UOS、麒麟 Kylin 等）；
  - 浏览器宿主环境：全面支持遵循 W3C 现代规范的浏览器，包括 Google Chrome 109+、Microsoft Edge 109+、Mozilla Firefox 115+、Apple Safari 16.4+ 等；
  - 网络要求：100% 离线脱网运行。所有力学矩阵求解、图线光栅化绘制、公式排版与 Excel 报表构建均在本地内存中完成。

### 2.2 离线单文件分发与运行方法

本软件提供绿色免安装与工程源码构建两种使用路径：

1. **绿色免安装运行**：
   - 获取单一发布文件 dist/index.html；
   - 直接使用鼠标双击该文件，或将其拖拽至任意现代浏览器窗口中；
   - 页面即刻离线加载并呈现主工作台，用户可直接开启气瓶设计工作。
2. **工程源码调试与本地构建流程**：
   - 依赖准备：宿主环境安装 Node.js 18.0.0+ 与 npm 包管理器；
   - 依赖安装：在工程根目录执行 npm install 安装所有开发依赖；
   - 开发调试：执行 npm run dev 启动热更新本地开发服务，访问 http://localhost:5173/ 开展交互调试；
   - 自动化测试：执行 npm test 运行全套单元测试，验证计算精度与逻辑一致性；
   - 编译单文件：执行 npm run build:single，调用 TypeScript 类型检查与 Vite 插件，编译输出便携式单文件 dist/index.html。
3. **桌面客户端封装（Tauri / Electron）**：
   - 系统支持通过 Tauri 框架封装为体积仅 3MB~5MB 的原生 Windows 桌面程序（.exe / .msi），也可通过 Electron 构建跨平台客户端，内核与界面功能保持完全一致。

## 3 软件总体架构与数据流转

### 3.1 系统分层架构设计

软件严格遵循关注点分离（Separation of Concerns）与单向数据流（Unidirectional Dataflow）设计原则，将数学力学计算内核与图形用户交互界面（UI）彻底解耦，系统总体分层架构如图 1 所示。

图 1  软件系统分层架构与数据流拓扑图

表现层（Presentation Layer）基于 React 19 构建，包含参数输入面板、铺层编辑表格、封头双视图、几何面板及公式帮助弹窗；状态管理层（State Layer）维护单一不可变状态源，调度微任务节流并在本地沙箱实现离线持久化；计算内核层（Core Engine）由材料推导、几何反解、测地线映射、网格理论及封头样条等多组无副作用纯函数构成；报表导出层（Export Engine）则通过底层协议将当前校核方案动态映射为符合行业标准的 Excel 活公式工作簿。

### 3.2 单向响应式数据流与计算机制

软件采用单向闭环的数据流转机制：
1. **输入捕获与防呆校验**：用户在输入面板或铺层表格修改参数时，输入组件首先执行数值与几何有效性校验（如半径 >0、层数为偶数等），防止非法数值污染内核。
2. **内核纯函数全量求解**：状态管理器触发全量计算流水线，由基础输入推导微观力学与几何派生量，再执行筒身网格计算与封头样条矩阵求解，最终输出完整的综合校核结果结构体。
3. **矢量视图并发重绘**：求解完成的校核结果对象通过状态订阅同步广播至各视图组件，驱动筒身承载指标、封头各层厚度曲线、母线爆压安全曲线等在浏览器当前渲染帧内瞬间完成重绘。

### 3.3 核心数据实体契约与接口规范

系统基于 TypeScript 强类型体系构建了严密的数据实体模型，核心数据实体规范见表 3。

表 3  系统核心数据实体模型规范

| 数据接口名称 | 字段组成 | 物理工程含义与说明 |
| --- | --- | --- |
| DesignInput | geometry, material, strength, requirement, constraint, plan | 聚合气瓶设计的完整要素输入（几何外形、材料物性、设计强度、额定工况、铺层约束与当前铺层方案） |
| GroupSpec | angle: number, layers: number, active?: boolean | 单个铺层角度组实体，包含缠绕螺旋角（度，环向层为 90°）、层数（物理缠绕要求为偶数）及激活状态 |
| LayupPlan | spiral: GroupSpec[], hoop: number | 完整铺层方案结构，包含螺旋角度组数组（数组先后顺序对应实际缠绕工艺顺序）与环向总层数 |
| DomeGroup | angle, layers, cycles, r0, rb, r2b, mR, V1, V2, m, valid | 封头单个角度组力学与几何样条模型参数，包含极孔半径、单/双倍带宽点、体积积分常数及三次样条系数 m1~m4 |
| CheckResult | derived, cylinder, dome, consistency, weight, verdict, diagnoses | 综合校核最终结果实体，包含微观力学派生量、筒身双向承载校核、封头厚度与爆压离散数组、赤道连续性状态、结构总重量与工程诊断建议 |

计算内核对外暴露一系列无副作用、无全局状态依赖的高性能纯函数 API：
- deriveParams(input: DesignInput): DerivedParams：由纤维线密度、带宽、体密度与强度参数推导单层厚度、排纱带宽及极限发挥强度；
- computeVolume(params: VolumeParams): VolumeParts：计算气瓶筒身容积、两端封头有效容积及总容积；
- solveGeometry(params: VolumeParams, unknown: UnknownField, targetL: number)：容积反向求解器，支持筒身长度闭式反解与内径/轴比高精度二分求根；
- windingTurns(R_in: number, l: number, lambda: number, r0: number)：求解单双程缠绕转角 θn 与候选数控线型切点；
- cylinderCheck(plan: LayupPlan, derived: DerivedParams, R: number): CylinderResult：执行筒身网格理论计算与纵横双向爆破压强校核；
- buildDomeGroups(plan: LayupPlan, derived: DerivedParams, R: number): DomeGroup[]：求解各螺旋角度组在封头近极孔过渡区的三次样条系数矩阵；
- domeCheck(groups: DomeGroup[], derived: DerivedParams, R: number): DomeResult：沿封头母线执行高密度离散采样、局部爆压空间判据计算与有效窗口极小值提取；
- runCheck(input: DesignInput): CheckResult：全流程总装校核入口函数，完成输入解析到综合诊断的全链路求解；
- autoDesign(input: DesignInput): DesignInput：启发式多目标自动铺层寻优算法入口；
- buildWorkbook(input: DesignInput, res: CheckResult): XLSX.WorkBook：构造带完整 Excel 活公式的计算书工作簿对象。

## 6 异常报错与处理机制

### 6.1 异常处理机制与安全防御策略

为确保软件在工程现场高频录入与复杂迭代过程中的高稳定性，系统构建了多层异常防御体系：
1. **视图层输入防呆与即时边界拦截**：所有输入框封装边界守卫，对非数值字符、负数、越界几何等进行前端阻断并高亮变红，防止非法数据流入；
2. **纯函数内核无副作用防御**：计算内核不修改任何全局状态，若输入参数触发不可求解分支，内核返回携带错误标志的结构化对象，保障应用界面不崩溃、不白屏；
3. **状态事务原子性保护**：每次状态变更均经过校验守卫，若新输入导致异常，状态管理器维持上一有效设计版本并给出提示。

| ERR-003 | 铺层层数奇数违规 | 在螺旋角度组中录入了奇数层（如 1、3、5 层） | 弹出工艺规范提示，输入框高亮黄色警示 | 物理螺旋缠绕必须为正负对称成对缠绕，请将层数调整为偶数 |
| ERR-004 | 材料物性参数异常 | 纤维体积比 Vf ≤ 0 或 ≥ 1，或材料密度 ≤ 0 | 阻止材料参数推导，派生量卡片显示警示符号 | 检查纤维工艺参数，通常碳纤维复合材料 Vf 处于 0.55~0.65 |
| ERR-005 | 封头判定窗口缺失 | 铺层方案中最高角度组极孔半径 r_boss ≥ R | 封头爆压曲线提示区间无效，禁止输出评估结论 | 降低最高角度组的螺旋角，确保各角度组能够进入封头铺展 |
| ERR-006 | 筒身爆破承载不足 | 筒身计算得 pa < pb 或 pth < pb | 承载指示卡片显示红色未达标，输出欠载警示 | 增加相应方向的铺层层数，或点击「自动生成铺层」重新寻优 |
| ERR-007 | 封头局部承载薄弱 | 封头母线判定窗口内存在 p_总(r) < pb | 爆压曲线上标注浅红色阴影区，并在波谷标注游标 | 适当增加高角度螺旋层层数，或将部分环向层置换为螺旋层 |
| ERR-008 | 赤道厚度不连续 | 封头赤道螺旋厚度与筒身螺旋厚度差值 > 0.01mm | 诊断面板弹出连续性警示，标注厚度跳变值 | 检查各组铺层层数与激活状态，确保模型数据流自洽 |
| ERR-009 | 容积求根不收敛 | 容积反求时输入目标容积超出物理几何可行域 | 求解器停止迭代，提示“未在有效区间内找到根” | 调整几何外形尺寸或目标容积，确保物理长径比处于合理范围 |
| ERR-010 | 本地存储读写受限 | 浏览器安全设置禁用了 localStorage 写入 | 控制台记录告警，自动切换为内存临时暂存模式 | 检查浏览器 Cookie 与本地存储权限设置，解除限制后刷新页面 |

### 6.3 故障排查与状态恢复流程

当用户在操作过程中遇到异常状态或界面显示不符合预期时，建议按以下标准流程进行排查恢复：
1. **核对输入边界与错误提示**：查看界面是否有高亮红框或黄色警示，对照表 5 修正非法数值；
2. **一键恢复基准状态**：点击主界面顶栏「恢复默认」按钮，系统将立即清空当前异常输入，加载内建的 140L/35MPa 标准工况基准模板，所有表格与图形恢复正常；
3. **清除浏览器沙箱缓存**：若因浏览器插件拦截导致异常，可通过浏览器设置清除该站点的 localStorage 缓存数据，重新打开 index.html 即可完成彻底重置；
4. **铺层方案智能自愈**：当遇到多层复杂方案承载不足时，推荐使用「自动生成铺层」功能，由系统内置算法重新进行层数分配与减重平衡。
