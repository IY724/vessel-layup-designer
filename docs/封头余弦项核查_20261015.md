# 封头余弦项核查

核查日期：2026-10-15。

## 结论

1. 课件使用余弦平方。原 XLS 的 `COS(u*COS(u))` 与课件不符，应修正这一余弦项。
2. `COS(u)^2` 是余弦平方的正确实现，但仅修正该项，不能认定现有封头逐点模型已完整符合课件。课件使用圆筒段角度 α₀，原表及此前局部修正版使用封头局部角 K。
3. V1.1.1 已同步网页、网站本地页面、桌面软件和 Excel 导出：局部曲线使用余弦平方；课件 α₀ 经验初估单独计算并用于初步判定。公开界面与导出不包含原版对比或修正提示。此前 5,990 个数值一致只证明原表复现，不证明原式正确。

## 课件证据

文件：`00_原始参考资料/附件/车载储氢复合材料气瓶（封头段）缠绕层厚度及强度校验(第六课) .pdf`，PDF 第 2 页。

等张力封头：

$$P_b=\frac{2\sigma_{fb}h_{f\alpha}\cos^2\alpha_0}{R}.$$

椭圆封头：

$$P_b=\frac{2k_s\sigma_{fb}h_{f\alpha}\cos^2\alpha_0}{R}.$$

同页明确将 α₀ 定义为圆筒段螺旋缠绕角。第二课第 3 页也区分固定的筒身角与沿封头变化的局部角。第六课将上述关系限定为初步设计的经验公式，没有在该页推导整条封头局部爆压曲线。

## 原 XLS 实现

文件：`00_原始参考资料/附件/封头厚度计算公式最终 - 演示版.xls`。

例如 `10!L23`：

```excel
2*J23*$C$15/$C$3*COS(K23/180*PI()*COS(K23/180*PI()))
```

其角度因子为 `cos(u cos u)`，其中 `u=K23*PI()/180`。六个角度组均检出了相同写法。

保持相同自变量、只修正平方项时，应为：

```excel
2*J23*$C$15/$C$3*COS(K23/180*PI())^2
```

这仍采用局部角 K。若声称严格使用课件列出的 α₀ 经验式，则需要明确采用各组圆筒段角度，而不能把 K 与 α₀ 当作同一变量。把经验式直接扩展为封头逐点强度分布，也需要独立依据。

课件采用纤维强度与纯纤维厚度之积。默认参数满足 `σc=Vf*σfb`，因此 `σc*t_composite=σfb*t_fiber`。若独立指定 σc 且破坏此关系，不能继续声称材料量与课件等价。

## 数值核查

仅检查同一自变量下的两种余弦项：

| u | cos(u cos u) | cos²u |
| --- | ---: | ---: |
| 10° | 0.985264727 | 0.969846310 |
| 45° | 0.849710492 | 0.500000000 |
| 60° | 0.866025404 | 0.250000000 |
| 90° | 1.000000000 | 0.000000000 |

固定原表厚度、角度、材料及 Ks=0.75，只把余弦项改成局部角余弦平方：

| 半径 r / mm | 原表爆压 / MPa | 仅修正平方项 / MPa |
| --- | ---: | ---: |
| 30.2 | 11.670751017 | 0.055914150 |
| 81 | 164.885975684 | 100.368248812 |
| 163 | 101.702290783 | 83.696838826 |
| 173.5 | 92.941380355 | 79.389865727 |

144 点中，最大差值为 64.517726872 MPa，出现在 r=81 mm，以上均已乘 Ks。该对比用于量化公式差异，不是对局部角模型或整瓶爆破压力的物理验证。
