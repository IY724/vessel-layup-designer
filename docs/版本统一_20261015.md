# V1.0 版本统一记录

2026-10-15。对外版本标识从 1.1.2 统一回 **V1.0**。

## 口径

- 版本源只有一个：`package.json` 的 `version`，现为 `1.0.0`（npm/electron-builder 要求三段式 semver）。
- 对外标识 = 版本源的主.次，渲染成 `V1.0`；界面、桌面窗口标题与「关于」、安装包文件名、文档标题、发布资产全部走这一条派生规则，不再出现第二种写法。
- 此前的 1.1.0 / 1.1.1 / 1.1.2 是 10-15 当天三次内部构建的构建号（公式同步、网格线同步各一次），不是对外版本；GitHub Release 一直叫 **V1.0**（tag `v1.0.0`），本次把软件内部的标识对齐到它。

## 改动点

| 位置 | 改法 |

| `desktop/main.cjs` | 窗口标题与「关于」对话框同样用派生的 `V1.0` |
| `desktop/builder.json` | 安装包与免安装文件名固定为 `气瓶铺层设计-1.0-Windows-x64-…`（electron-builder 只能插值完整 `${version}`，故写死，并由检查脚本兜住漂移） |

版本号出现在三处：网页与桌面的顶栏、状态栏、桌面「关于」对话框。窗口标题和浏览器标签页沿用页面主标题「复合材料气瓶缠绕铺层设计系统」，不带版本号——这一点改动前后一致，`desktop/main.cjs` 里给窗口设的标题会被页面的 `<title>` 覆盖。
